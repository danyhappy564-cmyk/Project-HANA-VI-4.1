```

● 왜 "업데이트"가 아니라 "포팅"인가

SPT는 4.0부터 서버 프로그램이 통째로 바뀌었습니다.
3.11까지는 자바스크립트 계열로 돌아갔는데, 4.0부터는 C#이라는 전혀 다른 언어입니다.

한글로 쓴 글을 영어로 옮기는 것에 가깝습니다.
맞춤법 몇 개 고치는 게 아니라 처음부터 다시 쓰는 작업입니다.

그래서 3.11 모드 파일을 4.1 폴더에 그냥 넣으면 서버가 아예 안 켜집니다.
원본 코드 약 1만 줄을 4.1 방식으로 새로 작성했습니다.


● 뭐가 들어있나

[1] HANA-VI's All In One — 총기 밸런스/호환 조정 42가지

    · SKS에 .366 TKM, ADAR에 .300 BLK 등 다구경 허용
    · VSS/AS VAL/AKS-74U 계열 다구경 + 탄창 확장
    · 방탄판 성능 상향, 마운트 차지공간 제거
    · 야시경 시야 확대, PNV-57E를 모든 야시경 슬롯에 허용
    · 그 외 부착물 호환 확장 다수

● 설치

1. 위 저장소에서 내려받습니다
2. .NET 10 SDK를 설치합니다 (https://dotnet.microsoft.com/download)
3. 저장소 폴더에서 아래 한 줄을 실행합니다

   dotnet build Project-HANA-VI-4.1.slnx -c Release

4. 끝입니다. SPT 폴더로 자동 복사되고, 배포용 zip도 같이 만들어집니다

SPT를 E:\SPT 4.1이 아닌 곳에 설치하셨으면 이렇게 하시면 됩니다:

   dotnet build Project-HANA-VI-4.1.slnx -c Release -p:SptRoot="D:\SPT 4.1"


● 이번 포팅의 장점 — 설정을 메모장으로 고칩니다

3.11 때는 "AK 연사속도를 700으로 바꾸고 싶다" 하면
프로그램 소스 코드를 직접 찾아서 고쳐야 했습니다.

4.1 포팅본은 수치와 대상 아이템을 전부 JSON 파일로 빼놨습니다.
메모장으로 열어서 숫자만 바꾸고 서버를 껐다 켜면 끝입니다.
프로그램 다시 만들 필요가 없습니다.

  user\mods\HANA_VI-AIO\config.json            ← 42가지 기능 켜고 끄기
  user\mods\HANA_VI-AIO\db\patches\*.json      ← 수치와 대상 아이템
  user\mods\HANA-VI_Items\db\packs.json        ← 아이템 팩 11개 켜고 끄기
  user\mods\HANA-VI-SuperAmmo\db\values.json   ← 탄약 최대 소지량, 색상

예를 들어 "방탄판 상향은 빼고 쓰고 싶다" 하시면
config.json에서 super_plates를 true → false로 바꾸시면 됩니다.

고친 뒤에 오타를 확인하는 검사 도구도 같이 넣어놨습니다.
(파이썬이 있으면 python3 tools/datacheck.py 로 돌립니다)


● 3.11과 달라진 점

의도적으로 다르게 만든 부분이 있습니다.

· 다른 모드가 빠져 있어도 서버가 안 죽습니다
  3.11은 참조하는 아이템이 하나라도 없으면 서버가 통째로 멈췄는데,
  4.1 포팅본은 경고만 남기고 그 항목만 건너뜁니다.

· 전체 적용 기능이 다른 모드 아이템에도 적용됩니다
  방탄판 상향, 마운트 차지공간 제거 같은 기능이
  3.11에서는 다른 모드가 추가한 아이템을 놓쳤는데 이제는 같이 적용됩니다.

· SVT-40 커스텀 마운트에 이름이 생겼습니다
  원본은 이름 파일이 빠져 있어서 게임에서 이름 없이 나왔습니다.

· 무기 프리셋 ID가 고정됐습니다
  원본은 서버를 켤 때마다 ID가 바뀌었습니다.

반대로, 원본에 있던 사소한 버그 몇 개는 일부러 그대로 뒀습니다.
고치면 밸런스가 3.11과 달라지기 때문입니다. 어디를 왜 그렇게 뒀는지는
저장소의 docs/PORTING-NOTES.md에 전부 적어놨습니다.
```
